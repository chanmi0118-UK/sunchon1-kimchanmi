전극도자절제술 사전교육 3D 영상 기획안 (예시)

  • 작성: 심장내과 간호팀 · 2026.10.07
  • 용어 표준: 심방세동(Atrial Fibrillation, AF) · 전극도자절제술(Radiofrequency Catheter Ablation, RFCA) — 이하 AF, RFCA로 통일
"보고 이해하면, 덜 두렵습니다"

SSituation - 현상/요약

  • RFCA 예정 고령 환자의 높은 시술 전 불안 및 정보 이해 부족 확인됨
  • 보고 목적: 5분 내외 3D 애니메이션 사전교육 영상 제작 승인 요청

BBackground - 배경/경과

항목내용
교육 대상70대 남성, 고혈압(HTN)·고지혈증·당뇨(DM) 동반, AF로 RFCA 예정
기기 활용스마트폰 사용 가능, 기기 조작 미숙
동행시술 시 보호자 동석 필요
현행 교육간호사 1:1 구두 설명, 환자당 15분 이상 반복
기존 영상서울아산병원 유튜브, Nucleus Medical Media — 전문용어 과다로 고령층 이해 곤란

AAssessment - 평가/분석

원인 분석

  • 시술 절차 불확실성 → 부작용 두려움 → 상태불안 상승
  • 구두 설명 의존 → 설명 품질 편차, 간호 인력 소모

매체 판단

  • 가상현실(Virtual Reality, VR): 고령자 오심·구토·어지러움 우려로 배제
  • 모니터·스마트폰 3D 영상: 접근성 높음, 반복 시청 가능 → 채택

예상 위험 요소 및 대응

위험 요소대응
근거 연구[1]가 외과 수술 환자 대상, RFCA 환자 직접 근거 아님RFCA 환자 대상 시범 적용(파일럿)으로 효과 먼저 확인 → R-3
영상 길이 5분, 선행 연구(약 15분)보다 짧음파일럿 결과 불안 감소 폭 미달 시 장면 추가·길이 조정
의료진 감수 전 영상 사용 시 정보 오류전문의 감수 + 내용 타당도 지수(Content Validity Index, CVI) 검증 후 사용 → R-6
청력·시력 저하, 기기 조작 미숙 고령자큰 자막·느린 말속도·성우 나레이션 필수, 간호사 첫 재생 지원 → R-2

5-1. 간호사 인건비 절감 추정 (③ 기준)

항목값출처
간호사 분당 인건비약 345원 (연 5,195만 원 ÷ 2,508시간 ÷ 60분)[2]
환자 1인당 대체 설명시간15분[1]
환자 1인당 절감액345원 × 15분 = 5,175원계산
연간 시술 건수(단일 기관)1,345건 (세브란스병원 2025년 심방세동 시술)[3]
연간 절감액(간호사 1명 설명 기준)5,175원 × 1,345건 = 약 696만 원/년계산
연간 절감액(질의응답 5분 잔존 시)345원 × 10분 × 1,345건 = 약 464만 원/년계산
연간 절감액(간호사 2명 설명 예시)약 696만 원 × 2명 = 약 1,392만 원/년예시

절감액 범위: 연 약 464만~696만 원(간호사 1명 기준). 696만 원은 15분 전부 대체 가정의 최대치. 연간 건수는 우리 병동 공개 자료 부재로 세브란스병원 수치[3] 대입, 실제 적용 시 병동 연간 시술 건수로 교체 필요. 선행 연구[1]는 외과 수술 환자 대상, 간호사 시간 절감은 정성적 서술만 존재 → 도입 후 실측 필요.

6. 내용 관리 및 필요 협진·요청

  • 심장내과 전문의 내용 감수 및 CVI 검증 요청 — [1]도 전문가 9명 CVI 0.96으로 검증
  • 시술 방식(고주파·냉각풍선·펄스장)별 차이: 짧은 설명 자막으로 처리, 공통 범위는 전문의 확인 필요
