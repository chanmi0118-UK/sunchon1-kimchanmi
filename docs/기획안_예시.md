# 전극도자절제술 사전교육 3D 영상 기획안 (예시)

- 작성: 심장내과 간호팀 · 2026.10.07
- 용어 표준: 심방세동(Atrial Fibrillation, AF) · 전극도자절제술(Radiofrequency Catheter Ablation, RFCA) — 이하 AF, RFCA로 통일
- 슬로건: "보고 이해하면, 덜 두렵습니다"
- 핵심 방향: 근거를 그대로 적용하지 않고, 파일럿으로 확인한 뒤 확대

---

## 기획안 한눈에 보기
- **대상:** RFCA 예정 고령 환자(70대 중심) 및 보호자
- **문제:** 시술 과정 불확실성·정보 부족, 반복 구두 설명으로 인한 불안 및 교육 편차
- **해결:** 약 5분 3D 영상 + 이해도 확인 3문항 + 필요 시 간호사 보충 설명
- **검증:** 선행 연구 효과 그대로 가정하지 않음, RFCA 환자 대상 소규모 파일럿으로 효과 확인
- **확대:** 효과·이해도·간호시간·비용 확인 후 병동 전체 적용

## S (Situation - 현상/요약)
- RFCA 예정 고령 환자의 높은 시술 전 불안 및 정보 이해 부족 확인됨
- 보고 목적: 약 5분 3D 사전교육 영상 제작 및 파일럿 후 병동 적용 승인 요청

| 항목 | 내용 |
|---|---|
| 주요 문제 | 시술·회복 과정 불확실성 → 불안 증가 가능성 |
| 교육 목표 | 시술 전체 흐름과 준비·회복·주의사항을 쉽게 이해, 필요 시 간호사 보충 설명으로 연결 |
| 제안 | 고령자가 반복 시청 가능한 약 5분 3D 교육 영상 제작 및 병동 적용 |

## B (Background - 배경/경과)
| 항목 | 내용 |
|---|---|
| 교육 대상 | 70대 남성, 고혈압(HTN)·고지혈증·당뇨(DM) 동반, AF로 RFCA 예정 |
| 기기 활용 | 스마트폰 사용 가능, 기기 조작 미숙 |
| 동행 | 시술 시 보호자 동석 필요 |
| 현행 교육 | 간호사 1:1 구두 설명, 환자당 15분 이상 반복 → 이해도·설명 편차 발생 |
| 기존 영상 | 서울아산병원 유튜브, Nucleus Medical Media — 전문용어 과다로 고령층 이해 곤란 |

**선행 연구[1]의 의미와 한계**

| 선행 연구 확인 내용 | 이번 기획안 해석 |
|---|---|
| 중국 대학병원 AF 카테터 절제술 환자 208명(평균 61세) 무작위 대조시험(Randomized Controlled Trial, RCT) | **RFCA 환자 대상 직접 근거** — 대상 질환·시술 일치 |
| 디지털 애니메이션 4편(입원·시술 전·시술 후·퇴원), 편당 5분 미만, iPad 시청 | 5분 이내 영상·태블릿 시청 설계와 일치 |
| 불안 점수(SAS) 애니메이션군 52.82 → 45.39점, 대조군 51.83 → 47.31점, 변화 차이 −2.91점(P<.001) | 애니메이션 교육의 불안 감소 근거 (그림 2) |
| 불안 측정 시점: 입원 시·퇴원 3개월 후 | **시술 직전 불안은 미측정 → 파일럿에서 별도 확인 필요** |
| 4단계 다회 교육 + 의사 강의 병행, 중국 단일 기관, 간호시간 미측정 | 영상 1편 단독 효과·간호시간 절감은 별도 검증 필요 |

- 수정 원칙: 선행 연구의 −2.91점은 「이번 영상의 예상 효과」로 확정하지 않음. 「선행 연구 참고 수치」로 표시하고 우리 병동 RFCA 환자 실제 효과는 파일럿으로 확인.

**AF 환자 대상 보완 근거[2]**

| 확인 내용 | 이번 기획안 활용 |
|---|---|
| 호주 대학병원 외래 AF 환자 204명(평균 65세) 무작위 대조시험 | RFCA 시술 전 교육은 아니나 **AF 환자 영상 교육의 지식 향상 확인** — [1] 보완 |
| 의료진 제작 영상 4편 + 주 1회 재시청 링크 → 90일 후 AF 지식 정답 가능성 1.23배(OR 1.23, p=.04) | 영상 교육의 지식 향상 근거 |
| 3회 이상 재시청 환자 효과 더 큼(OR 1.46, p=.003) | 반복 시청 설계 근거 (참고: R-1) |
| 시청 2일 후에는 지식 차이 없음(OR 1.11, p=.38) | 단기 측정만으로 판단 금지, 추적 측정 근거 (참고: R-3-1) |
| RFCA 시술 전 교육 아님, 불안 미측정, 만족도 차이 없음 | 불안 감소 근거는 [1] 사용, 만족도 향상은 기대효과로 내세우지 않음 |

## A (Assessment - 평가/분석)
- **원인 분석**
  - 시술 절차 불확실성 → 부작용 두려움 → 상태불안 상승
  - 구두 설명 의존 → 설명 품질 편차, 간호 인력 소모
- **매체 판단**
  - 가상현실(Virtual Reality, VR): 고령자 오심·구토·어지러움 우려로 배제
  - 모니터·스마트폰 3D 영상: 접근성 높음, 반복 시청 가능 → 채택
- **예상 위험 요소 및 대응**

| 위험 요소 | 대응 |
|---|---|
| 근거 연구[1]의 불안 측정 시점이 퇴원 3개월 후, 시술 직전 불안 아님 | 파일럿에서 시술 직전(시술실 이송 전) 불안 별도 측정 (참고: 3. 파일럿 검증 계획) |
| [1]은 4단계 다회 교육, 이번 기획은 시술 전 영상 1편 중심 | 효과 미리 단정하지 않음, 파일럿 결과에 따라 퇴원 교육 클립 추가 검토 |
| 고령자의 태블릿·QR 단독 사용 어려움 | 간호사 첫 재생 지원, 병동 태블릿 이용, 시청 직후 3문항 확인 (참고: 2. 운영 계획) |
| 지침 변경 시 영상 내용 오류 | 공통 내용과 병원별 내용 분리, 금식·침상안정은 카드·자막 모듈로 즉시 수정 (참고: 6. 내용 관리) |
| 간호시간 절감액 과대평가 | 영상 시청시간이 아닌 실제 간호사 직접 설명시간을 도입 전후 측정, 보충 설명 포함 재계산 (참고: 5-1) |

## R (Recommendation - 제안/계획)
**1. 영상 구성 (총 약 5분)**

| 장면 | 시간 | 핵심 내용 | 자막 + 성우 나레이션 | 제작 원칙 |
|---|---|---|---|---|
| ① AF란? | 0:00–0:50 | 심방세동 개념, 심장 리듬 변화 3D 표현 | "심장이 불규칙하게 뛰는 병, 심방세동임" | 의학용어 최소화, 3D 그림 중심 |
| ② 시술 전 준비 | 0:50–1:50 | 금식·복약·준비물 | "병원 안내 시간부터 금식 필요" | **병원 지침 확정 후 최종 문구 삽입** |
| ③ 시술 과정(3D) | 1:50–3:20 | 마취 → 카테터 삽입 → 좌심방 진입 → 폐정맥 절제 | "다리 혈관으로 가는 관을 넣어 시술함" | 방식별(고주파·냉각풍선·펄스장) 차이는 별도 안내 |
| ④ 시술 후 회복 | 3:20–4:20 | 지혈·침상안정·회복 관찰 | "안내 시간 동안 다리 움직임 제한 필요" | **병원별 지침에 맞춰 수정 가능하도록 모듈화** |
| ⑤ 주의 증상 | 4:20–5:00 | 출혈·흉통·호흡곤란 시 알리기 | "이상 증상 시 참지 말고 즉시 간호사 호출 필요" | 「참지 말고 알리기」 명확 제시 |

- 5분 구성 이유: 핵심 정보 5개 영역 압축, 반복 시청 용이 — [1]도 애니메이션 편당 5분 미만으로 제작
- 반복 시청 설계: [2]에서 3회 이상 재시청 환자의 지식 효과 더 큼(OR 1.46) → QR로 입원 중·퇴원 후 재시청 안내
- 제작 원칙: 큰 글씨·높은 가독성·느린 말속도·명확한 성우 나레이션, 한 화면 한 메시지
- 금식 시간·침상안정 시간 등 구체 수치는 담당 의료진 최종 확인 후 입력

**2. 운영 계획 — 시청 → 이해 확인 → 보충 설명**
- ① 간호사 첫 재생 지원(버튼 1개 화면) → ② 환자·보호자 시청(보호자 미동반 시 병동 태블릿) → ③ 이해도 3문항(시청 직후) → ④ 오답 시 보충 설명(해당 장면 재시청 + 간호사) → ⑤ 소요시간 기록(보충 설명 시간 포함)

| 상황 | 운영 방법 |
|---|---|
| 기기 조작 어려움 | 간호사 첫 재생 지원, 버튼 1개 구조로 화면 단순화 |
| 보호자 동반 | 환자·보호자 함께 시청 권장 |
| 보호자 미동반 | 간호사실 근처에서 병동 태블릿으로 시청 지원 |
| 시청 후 이해 부족 | 3문항 중 1개라도 오답 시 해당 장면 재시청 + 간호사 짧은 보충 설명 |
| 시간 측정 | 영상 시청시간과 별도로 간호사 실제 보충 설명시간 기록 |

**2-1. 이해도 확인 3문항 (시청 직후)**

| 번호 | 확인 내용 | 정답·판정 | 확인 장면 |
|---|---|---|---|
| 1 | 시술 전 병원에서 안내한 금식 방법을 알고 있는가? | 병원 확정 지침과 일치 시 정답 | ② 시술 전 준비 |
| 2 | 시술 후 회복 과정에서 지켜야 할 사항을 알고 있는가? | 병원 확정 지침과 일치 시 정답 | ④ 시술 후 회복 |
| 3 | 시술 후 이상 증상(출혈·가슴 통증·숨참)이 생기면 어떻게 하는가? | 즉시 의료진에게 알림 | ⑤ 주의 증상 |

- 응답 방식: 큰 글씨·그림 버튼으로 선택, 보호자 대신 응답 불가
- 「자정부터 금식」「몇 시간 다리 움직임 제한」 등은 병원 지침 확정 전 정답 문항으로 고정하지 않음

**3. 파일럿 검증 계획**
- 핵심: 「영상이 효과 있을 것」이 아니라 「우리 RFCA 환자에게 실제로 효과 있는지 확인 후 확대」

| 단계 | 실행 | 판정 |
|---|---|---|
| ① 사전 측정 | 입원 시 불안·정보요구 평가 | 기초값 확보 |
| ② 영상 시청 | 약 5분 영상 시청 | 시청 완료 여부 기록 |
| ③ 사후 측정 | 시술실 이송 전 동일 척도 재측정 + 이해도 3문항 + 만족도 | 변화량 확인 |
| ④ 기존 교육과 비교 | 도입 전 기존 구두 교육 환자군과 비교 | 두 군 차이 확인 |
| ⑤ 운영성 평가 | 간호사 설명시간·보충 설명시간·기기 사용 어려움 기록 | 실제 업무량 확인 |

**3-1. 평가 도구 및 효과 판정 기준**

| 항목 | 내용 |
|---|---|
| 불안 도구 | 시술 전: 수술 전 불안·정보요구 척도(Amsterdam Preoperative Anxiety and Information Scale, APAIS), 11점 이상 불안 판정 / 추적: 자가평가 불안 척도(Self-rating Anxiety Scale, SAS) — [1]과 같은 도구로 결과 비교 |
| 지식 점수 | 영상 내용 기반 자체 문항, 심장내과 전문의 감수 + 재시청 횟수 기록 |
| 측정 시점 | 사전: 입원 시 / 사후: 시술실 이송 전(시술 직전 불안) / 추적: 퇴원 3개월 후 SAS — [1]과 동일 시점, 퇴원 후 외래 방문 시 지식 재측정 — [2]에서 2일 후 차이 없음, 90일 후 차이 확인 |
| 비교군 | 도입 전 일정 기간 환자(기존 구두 설명) vs 도입 후 환자 — 가능 시 [1]처럼 무작위 배정 |
| **판정 기준** | 1차: 시청 전후 불안 점수 변화 / 2차: 기존 교육군 대비 불안 점수 / 3차: 이해도 정답률·시청 완료율 / 4차: 간호사 직접 설명시간 감소 / 5차: 환자·간호사 만족도 및 운영 문제 |

- p<.05 하나만으로 성공 판단하지 않음. 소규모 파일럿은 평균 변화량·이해도·시청 완료율·실제 간호시간 감소를 함께 보고 확대 여부 결정.

**4. 실행 로드맵**

| 단계 | 주요 업무 | 완료 기준 |
|---|---|---|
| 1. 기획 확정 | 대상·핵심 메시지·병원 지침 확인 | 의료진 합의 |
| 2. 콘텐츠 제작 | 스토리보드·3D 영상·성우 나레이션 제작 | 초안 완성 |
| 3. 의료 검증 | 심장내과 전문의 감수, 내용 타당도 지수(Content Validity Index, CVI) 검토 | 배포 승인 |
| 4. 파일럿 | RFCA 환자 대상 사전·사후 평가 | 효과·이해도·운영성 자료 확보 |
| 5. 개선 | 영상 길이·자막·설명 내용 수정 | 파일럿 문제 해결 |
| 6. 확대 | 병동 전체 적용 | 표준 교육 절차로 정착 |
| 7. 유지관리 | 연 1회 및 지침 변경 시 점검 | 최신 버전 유지 |

**5. 기대효과**
- 환자 측면: 시술 과정 사전 시각화, 반복 시청으로 불확실성 감소
- 교육 측면: 간호사별 설명 편차 감소, 핵심 내용 표준화
- 업무 측면: 단순 반복 설명 일부 대체, 이해 부족 환자에게 간호 집중
- 관리 측면: 이해도·불안·간호시간 수치화로 효과 지속 평가

선행 연구[1] 참고 수치 — 이번 영상의 확정 효과 아님, 파일럿으로 재확인 필요

| 효과 | 선행 연구 수치 | 의미 |
|---|---|---|
| ① 불안 감소 (그림 2) | 애니메이션군 52.82 → 45.39점(−7.43점) / 대조군 51.83 → 47.31점(−4.52점) / 변화 차이 −2.91점(P<.001) [1] | 기존 교육보다 불안 감소 폭 큼 |
| ② 복약 순응도 향상 | 애니메이션군 17.04 → 20.13점 / 대조군 17.14 → 18.47점 / 변화 차이 1.76점(P<.001) [1] | 시술 후 자기관리 개선 |
| ③ AF 지식 향상 | 90일 후 지식 정답 가능성 1.23배(OR 1.23, p=.04), 3회 이상 재시청 시 1.46배 [2] | 반복 시청 설계의 근거 |

**5-1. 간호시간 절감액**
- **연간 절감액 = 환자 1인당 실제 감소한 간호사 직접 설명시간 × 간호사 분당 인건비 × 우리 병동 실제 연간 RFCA 건수**
- 측정 항목: 기존 1:1 구두 설명 평균 시간 / 도입 후 영상 지원 + 보충 설명 평균 시간 / 두 시간의 차이
- 연간 건수: 타 기관 수치가 아닌 우리 병동 최근 1년 또는 2~3년 평균 RFCA 건수로 교체

참고: 최대치 시나리오 (도입 전 산출, 확정 금액 아님)

| 항목 | 값 | 출처 |
|---|---|---|
| 간호사 분당 인건비 | 약 345원 (연 5,195만 원 ÷ 2,508시간 ÷ 60분) | [3] |
| 참고 연간 건수 | 1,345건 (세브란스병원 2025년 심방세동 시술) | [4] |
| 15분 전부 대체 시(최대치) | 345원 × 15분 × 1,345건 = 약 696만 원/년 | 계산 |
| 질의응답 5분 잔존 시 | 345원 × 10분 × 1,345건 = 약 464만 원/년 | 계산 |
| 간호사 2명 설명 예시 | 약 696만 원 × 2명 = 약 1,392만 원/년 | 예시 |

- 세브란스 1,345건은 우리 병동 공개 건수 부재로 쓴 참고 수치임. 15분은 현행 구두 설명 시간(B 배경) 기준 가정이며 선행 연구에 간호시간 자료 없음. 실제 절감액 계산에는 우리 병동 건수와 도입 후 실측 시간 사용.

**5-2. 비용 및 투자 회수 기간**

| 항목 | 현재 상태 | 보완 방법 |
|---|---|---|
| 3D 영상 제작 | 업체 견적 미확정 | 2~3개 업체 견적 비교 |
| 전문의 감수·CVI | 비용 미확정 | 심장내과 감수 범위와 검증 방법 확정 |
| 태블릿·QR | 비용 미확정 | 기존 병동 장비 활용 가능 여부 확인 |
| 유지·수정 | 연 1회 점검 | 지침 변경 시 즉시 수정 비용과 담당자 지정 |

- **투자 회수 기간(년) = 총 초기 제작·도입비 ÷ 연간 실제 절감액**
- 초기 비용과 실제 절감액 확인 전에는 회수 기간 확정하지 않음
- 비교안: 기존 무료 영상(서울아산병원 유튜브 등) 재활용안과 비용·이해도 비교

**6. 내용 관리 및 필요 협진·요청**

| 문제 | 관리 방법 |
|---|---|
| 시술 방식 차이(고주파·냉각풍선·펄스장) | 공통 흐름 중심 설명, 방식별 차이는 짧은 카드·자막으로 보완 |
| 금식·복약·침상안정 지침 변경 | 영상 본편과 분리한 카드·자막 모듈로 관리 |
| 의료정보 오류 | 배포 전 심장내과 전문의 감수 및 CVI 검토 |
| 책임자 부재 | 간호팀 내 영상 관리 담당자 지정, 변경 이력 기록 |
| 정기 점검 | 최소 연 1회 + 병원 지침 변경 시 즉시 검토 |

- 협진 요청: 심장내과 전문의 내용 감수·CVI 검증, 의료정보팀 QR·태블릿 배포 협조

> **최종 제안:** 선행 연구 효과를 그대로 적용하는 사업이 아닌, 고령 RFCA 환자용 3D 사전교육 영상 개발 → 소규모 파일럿으로 불안 감소·이해도·간호시간 절감 확인 → 병동 전체 확대의 단계적 교육개선 사업임.
