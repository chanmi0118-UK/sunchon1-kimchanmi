# 전극도자절제술 사전교육 3D 영상 기획안 (예시)

- 작성: 심장내과 간호팀 · 2026.10.07
- 용어 표준: 심방세동(Atrial Fibrillation, AF) · 전극도자절제술(Radiofrequency Catheter Ablation, RFCA) — 이하 AF, RFCA로 통일
- 슬로건: "보고 이해하면, 덜 두렵습니다"

---

## S (Situation - 현상/요약)
- RFCA 예정 고령 환자의 높은 시술 전 불안 및 정보 이해 부족 확인됨
- 보고 목적: 5분 내외 3D 애니메이션 사전교육 영상 제작 승인 요청

## B (Background - 배경/경과)
| 항목 | 내용 |
|---|---|
| 교육 대상 | 70대 남성, 고혈압(HTN)·고지혈증·당뇨(DM) 동반, AF로 RFCA 예정 |
| 기기 활용 | 스마트폰 사용 가능, 기기 조작 미숙 |
| 동행 | 시술 시 보호자 동석 필요 |
| 현행 교육 | 간호사 1:1 구두 설명, 환자당 15분 이상 반복 |
| 기존 영상 | 서울아산병원 유튜브, Nucleus Medical Media — 전문용어 과다로 고령층 이해 곤란 |

## A (Assessment - 평가/분석)
- **원인 분석**
  - 시술 절차 불확실성 → 부작용 두려움 → 상태불안 상승
  - 구두 설명 의존 → 설명 품질 편차, 간호 인력 소모
- **매체 판단**
  - 가상현실(Virtual Reality, VR): 고령자 오심·구토·어지러움 우려로 배제
  - 모니터·스마트폰 3D 영상: 접근성 높음, 반복 시청 가능 → 채택
- **예상 위험 요소 및 대응**

| 위험 요소 | 대응 |
|---|---|
| 근거 연구[1]가 외과 수술 환자 대상, RFCA 환자 직접 근거 아님 | RFCA 환자 대상 시범 적용(파일럿)으로 효과 먼저 확인 → R-3 |
| 영상 길이 5분, 선행 연구(약 15분)보다 짧음 | 파일럿 결과 불안 감소 폭 미달 시 장면 추가·길이 조정 |
| 의료진 감수 전 영상 사용 시 정보 오류 | 전문의 감수 + 내용 타당도 지수(Content Validity Index, CVI) 검증 후 사용 → R-6 |
| 청력·시력 저하, 기기 조작 미숙 고령자 | 큰 자막·느린 말속도·성우 나레이션 필수, 간호사 첫 재생 지원 → R-2 |

## R (Recommendation - 제안/계획)
**1. 영상 구성 (총 약 5분)**

| 장면 | 시간 | 내용 | 자막 + 성우 나레이션 |
|---|---|---|---|
| ① AF란? | 0:00–0:50 | 심장 리듬 이상 3D 표현 | "심장이 불규칙하게 뛰는 병, 심방세동임" |
| ② 시술 전 준비 | 0:50–1:50 | 금식·복약·준비물 | "시술 전날 자정부터 금식 필요" |
| ③ 시술 과정(3D) | 1:50–3:20 | 마취 → 카테터 삽입 → 좌심방 진입 → 폐정맥 절제 | "다리 혈관으로 가는 관을 넣어 시술함" |
| ④ 시술 후 회복 | 3:20–4:20 | 침상안정·지혈 | "시술 후 다리 움직임 제한 필요" |
| ⑤ 주의 증상 | 4:20–5:00 | 출혈·흉통·호흡곤란 시 연락 | "이상 증상 시 즉시 간호사 호출 필요" |

- 장면 내용 문구는 예시임, 금식 시간·안정 시간 등 세부 지침은 의료진 확인 후 확정 필요

- 5분 구성 이유: 70대 대상자 집중 시간 고려, 핵심 정보 5개(질환·준비·과정·회복·주의 증상)만 압축, 반복 시청 부담 적음
- 영상 구조: 공통 부분(①·③·⑤)과 병원별 부분(②·④의 금식·침상안정 시간) 분리 → 지침 변경 시 병원별 부분만 자막·안내 카드로 교체

**2. 운영 계획 — 시청 지원 절차**
- ① 간호사가 첫 재생 지원(버튼 1개 화면) → ② 환자·보호자 시청(보호자 미동반 시 간호사실 근처 병동 태블릿) → ③ 이해도 체크 3문항 → ④ 오답 시 간호사 1:1 보충 설명
- 시청 방식: 병동 태블릿 및 QR코드, 보호자 동반 시청 권장
- 보충 설명 시간은 간호사 투입시간에 포함해 함께 측정 → 5-1 절감액 보정

**3. 실행 단계**

| 단계 | 내용 | 다음 단계 조건 |
|---|---|---|
| ① 제작·검증 | 3D 영상 제작, 심장내과 전문의 감수, CVI 검증 | CVI 기준 충족 |
| ② 파일럿 | RFCA 환자 소규모 적용, 사전·사후 불안 점수 측정 | 불안 점수 유의한 감소 |
| ③ 효과 판정 | 도입 전 환자와 비교(4. 평가 설계 기준) | 판정 기준 충족 |
| ④ 병동 확대 | 전체 RFCA 예정 환자 적용, 연 1회 내용 점검 | — |

**4. 평가 설계**

| 항목 | 내용 |
|---|---|
| 불안 도구 | 수술 전 불안·정보요구 척도(Amsterdam Preoperative Anxiety and Information Scale, APAIS) — [1]과 같은 도구로 결과 비교 가능, 11점 이상 불안 판정 |
| 지식 점수 | 영상 내용 기반 자체 문항, 심장내과 전문의 감수 |
| 측정 시점 | 사전: 입원 시 / 사후: 시술실 이송 전 — [1]과 동일 |
| 비교군 | 도입 전 일정 기간 환자(기존 구두 설명) vs 도입 후 환자 — [1]과 같은 순차 수집 방식 |
| 기타 지표 | 간호사 교육 소요시간(보충 설명 포함), 만족도 |
| **효과 판정 기준** | 사후 불안 점수 비교군보다 통계적으로 낮음(p<.05) / 11점 미만 비율 증가 / 간호사 설명 시간 감소 |

**5. 기대효과**
- 선행 연구[1] 결과 기준. 영상 1편이 ① 환자 불안 감소, ② 정보요구 충족, ③ 간호사 1:1 설명 시간 대체를 동시에 달성하는 구조임.

| 효과 | 근거 수치 | 의미 |
|---|---|---|
| ① 수술 전 불안 감소 (그림 2) | 영상 시청군 11.67 → 8.09점(−3.58점, −30.7%) / 대조군 9.25 → 9.55점 / 사후 두 군 차이 p=.014 [1] | 불안 기준(11점) 이상 → 기준 미만으로 하강 |
| ② 정보요구도 감소 | 영상 시청군 6.00 → 3.99점(−2.01점, −33.5%) / 대조군 5.43 → 5.55점 / 사후 두 군 차이 p<.001 [1] | 불안 원인인 정보 부족 해소 → ①의 기전 |
| ③ 간호사 설명 시간 대체 | 구두 상담 간호사 1:1 최소 15분 → 영상 약 15분 환자 자가 시청 [1] | 환자 교육시간은 유지, 간호사 직접 설명 시간만 대체 |

**5-1. 간호사 인건비 절감 추정 (③ 기준)**

| 항목 | 값 | 출처 |
|---|---|---|
| 간호사 분당 인건비 | 약 345원 (연 5,195만 원 ÷ 2,508시간 ÷ 60분) | [2] |
| 환자 1인당 대체 설명시간 | 15분 | [1] |
| 환자 1인당 절감액 | 345원 × 15분 = 5,175원 | 계산 |
| 연간 시술 건수(단일 기관) | 1,345건 (세브란스병원 2025년 심방세동 시술) | [3] |
| **연간 절감액(간호사 1명 설명 기준)** | 5,175원 × 1,345건 = **약 696만 원/년** | 계산 |
| 연간 절감액(질의응답 5분 잔존 시) | 345원 × 10분 × 1,345건 = **약 464만 원/년** | 계산 |
| 연간 절감액(간호사 2명 설명 예시) | 약 696만 원 × 2명 = 약 1,392만 원/년 | 예시 |

- 절감액 범위: 연 약 464만~696만 원(간호사 1명 기준). 696만 원은 15분 전부 대체 가정의 최대치. 연간 건수는 우리 병동 공개 자료 부재로 세브란스병원 수치[3] 대입, 실제 적용 시 병동 연간 시술 건수로 교체 필요. 선행 연구[1]는 외과 수술 환자 대상, 간호사 시간 절감은 정성적 서술만 존재 → 도입 후 실측 필요.

**5-2. 비용 및 투자 회수 기간**

| 비용 항목 | 금액 |
|---|---|
| 3D 영상 제작비 | 업체 견적 2~3곳 확보 후 기재 |
| 전문의 감수·CVI 검증 | 확인 후 기재 |
| 태블릿·QR 배포 | 의료정보팀 협의 후 기재 |
| 지침 변경 시 수정·유지 | 연 1회 점검 기준 확인 후 기재 |
| **투자 회수 기간(년)** | **총비용 ÷ 연 절감액(약 464만~696만 원)** |

- 비교안: 기존 무료 영상(서울아산병원 유튜브 등) 재활용안과 비용·이해도 비교 필요
- 금액 미환산 효과: 환자 불안 감소, 교육 내용 표준화

**6. 내용 관리 및 필요 협진·요청**
- 심장내과 전문의 내용 감수 및 CVI 검증 요청 — [1]도 전문가 9명 CVI 0.96으로 검증
- 시술 방식(고주파·냉각풍선·펄스장)별 차이: 짧은 설명 자막으로 처리, 공통 범위는 전문의 확인 필요
- 간호팀 내 영상 관리 담당자 지정, 연 1회 및 지침 변경 시 수정
- 의료정보팀 QR·태블릿 배포 협조 요청

### 캡션 예시
- **[그림 1] 시술 과정 5단계 일러스트** — 준비부터 회복까지 흐름 한눈에 확인 가능. 시술 전 1회 시청 권장.
- **[그림 2] 영상 시청 전후 수술 전 불안 점수 비교 막대그래프** — 영상 시청군 불안 점수 11.67 → 8.09점 감소, 대조군 변화 없음(9.25 → 9.55). 기대효과 ①·② 근거. 병동 도입 검토 필요.
