**Q1. 근거 연구의 대상 적합성**
선행 연구[1]는 말레이시아 사립병원 외과 수술 환자(전신·척추마취, 70세 이상 5명) 대상 결과임. 국소·진정 마취로 RFCA를 받는 70대 AF 환자에게 같은 불안 감소 효과를 기대할 수 있는 근거는 무엇인가?

**답변 예시**
- 인정: 선행 연구[1]는 외과 수술 환자 대상, RFCA 환자 직접 근거 아님
- 근거: 불안 원인(절차 불확실성·정보 부족)은 수술·시술 공통 / [1]에서 정보요구도 감소(6.00 → 3.99)와 불안 감소(11.67 → 8.09) 동반 확인됨
- 보완: RFCA 환자 대상 소규모 시범 적용(파일럿) 후 사전·사후 불안 점수 측정 → 효과 확인 시 확대

**Q2. 영상 길이 차이**
선행 연구 영상은 약 15분, 이번 기획 영상은 약 5분임. 시청 시간이 1/3로 줄어도 불안 점수 −3.58점, 정보요구도 −2.01점 수준의 효과가 유지된다고 볼 수 있는가?

**답변 예시**
- 인정: 5분 영상의 효과 근거는 아직 없음
- 근거: 70대 대상자의 집중 시간 고려, 핵심 정보 5개(질환·준비·과정·회복·주의 증상)만 압축 / 짧은 영상은 반복 시청 부담 적음
- 보완: 파일럿에서 불안 점수 감소 폭이 [1]보다 크게 낮으면 장면 추가 또는 길이 조정

**Q3. 인건비 절감 산정의 전제**
연 696만 원은 영상이 간호사 설명 15분을 전부 대체한다는 최대치 가정임. 시청 후 질의응답·확인 시간은 얼마로 보고 있으며, 세브란스병원 연 1,345건을 우리 병동 건수로 대신 쓴 이유는 무엇인가?

**답변 예시**
- 인정: 연 696만 원은 15분 전부 대체를 가정한 최대치임
- 예시 계산: 시청 후 질의응답에 5분이 남는다면 절감 시간 10분 → 345원 × 10분 × 1,345건 = 약 464만 원/년
- 세브란스 건수 사용 이유: 우리 병동 건수는 공개 자료 없음, 국내 공개 수치 중 심방세동 시술만 따로 집계한 최신 연간 수치
- 보완: 실제 적용 시 우리 병동 연간 시술 건수로 교체, 도입 전후 간호사 설명 시간 직접 측정

**Q4. 비용 대비 효과**
기대효과에 절감액만 있고 3D 영상 제작비, 전문의 감수 비용, 태블릿·QR 배포 비용, 지침 변경 시 수정 비용이 없음. 투자비 회수까지 몇 년이 걸리는가?

**답변 예시**
- 인정: 제작·감수·배포·수정 비용 미산정
- 계산 틀: 회수 기간(년) = 총비용 ÷ 연 절감액(약 464만~696만 원)
- 보완: 제작 업체 견적 2~3곳 확보 후 표에 추가 / 기존 무료 영상 재활용안과 비용 비교
- 추가 논점: 불안 감소·교육 표준화는 금액으로 환산되지 않는 효과임

**Q5. 대상자의 실제 시청 가능성**
교육 대상은 기기 조작 미숙, 청력·시력 저하 가능성이 있는 70대임. 보호자가 동반하지 못할 때 태블릿·QR 방식으로 혼자 끝까지 시청하고 이해했는지 어떻게 확인하는가?

**답변 예시**
- 기존 계획: 큰 자막·느린 말속도·성우 나레이션, 시청 후 이해도 체크 3문항
- 보완: 간호사가 첫 재생만 도움(버튼 1개 화면) / 보호자 미동반 시 간호사실 근처에서 병동 태블릿으로 시청
- 확인 방법: 이해도 체크 3문항 중 오답 발생 시 간호사 1:1 보충 설명
- 연결 논점: 보충 설명 시간만큼 Q3 절감액 감소 → 도입 후 함께 측정 필요

**Q6. 효과 평가 설계**
평가 지표에 불안척도·지식 점수·교육 소요시간·만족도가 있으나 측정 도구(예: APAIS, STAI), 측정 시점, 비교군이 없음. 도입 후 "효과 있음"을 무엇으로 판정하는가?

**답변 예시**
- 불안 도구: 수술 전 불안·정보요구 척도(Amsterdam Preoperative Anxiety and Information Scale, APAIS) — [1]과 같은 도구라 결과 비교 가능, 11점 이상을 불안으로 판정
- 지식 점수: 영상 내용 기반 자체 문항, 심장내과 전문의 감수
- 측정 시점: 입원 시(사전) / 시술실 이송 전(사후) — [1]과 동일
- 비교군: 도입 전 일정 기간 환자(기존 구두 설명) vs 도입 후 환자 — [1]도 대조군 먼저, 중재군 나중 순서로 수집
- 판정 기준: 사후 불안 점수가 비교군보다 통계적으로 낮음(p<.05), 11점 미만 비율 증가, 간호사 설명 시간 감소

**Q7. 내용 정확성과 유지 관리**
RFCA는 고주파·냉각풍선·펄스장 절제술 등 방식이 다양하고 병원마다 금식·침상안정 지침이 다름. 영상 1편으로 모두 다룰 수 있는가, 지침이 바뀌면 누가 언제 영상을 수정하는가?

**답변 예시**
- 구조: 공통 부분(AF 설명·카테터 삽입·회복·주의 증상)과 병원별 부분(금식·침상안정 시간) 분리 → 병원별 부분만 자막·안내 카드로 쉽게 교체
- 시술 방식: 환자가 겪는 과정은 공통 부분이 많을 것으로 예상됨(전문의 확인 필요), 방식별 차이는 짧은 설명 자막으로 처리
- 검증: 전문가 내용 타당도 지수(Content Validity Index, CVI) 확인 — [1]도 전문가 9명 CVI 0.96으로 검증함
- 유지: 심장내과 전문의 감수, 간호팀 담당자 지정, 연 1회 및 지침 변경 시 수정
