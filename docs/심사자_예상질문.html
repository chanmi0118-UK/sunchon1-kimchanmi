AI 심사자 예상 질문 7개·답변 예시

  • 대상 문서: 전극도자절제술 사전교육 3D 영상 기획안 (2026.10.07, 선행 연구[1] Shi 2025 기준)
  • 용도: 발표 전 자기 점검용, 기획안 본문 미포함
  • 답변 원칙: 약점 인정 → 근거 → 보완 계획 순서, 근거 없는 수치 단정 금지 / 답변은 예시, 본인 말투로 바꿔 사용 필요

Q1불안 측정 시점

선행 연구[1]는 불안을 입원 시와 퇴원 3개월 후에 측정함. 시술 직전 불안은 측정하지 않았는데, 이 결과를 「시술 전 불안 감소」의 근거로 쓸 수 있는가?

답변 예시

  • 인정[1]은 시술 직전 불안 미측정, 퇴원 3개월 후 불안 감소 근거임
  • 근거[1] 대상이 AF 카테터 절제술 환자로 시술 일치 / 애니메이션군 52.82 → 45.39점, 대조군 51.83 → 47.31점, 변화 차이 −2.91점(P<.001)
  • 보완파일럿에서 시술실 이송 전 불안(APAIS) 별도 측정 → 시술 직전 효과는 우리 자료로 확인

Q2교육 방식 차이

[1]은 입원·시술 전·시술 후·퇴원 4단계 애니메이션 + 의사 강의 병행 방식임. 이번 기획은 시술 전 영상 1편 중심인데 같은 효과를 기대할 수 있는가?

답변 예시

  • 인정[1] 결과는 다단계 교육 전체 효과, 영상 1편 단독 효과 아님
  • 근거[1]도 편당 5분 미만 → 5분 영상 1편 길이는 동일 수준 / [2]에서 3회 이상 재시청 시 지식 효과 더 큼(OR 1.46)
  • 보완QR 재시청으로 반복 노출 확보, 파일럿 결과에 따라 퇴원 교육 클립 추가 검토

Q3효과 크기

[1]에서 대조군도 불안이 4.52점 감소했고, 애니메이션군과의 차이는 2.91점임. 이 차이가 환자에게 체감될 만큼 의미 있는 크기인가?

답변 예시

  • 인정대조군도 기존 교육으로 감소, 순수 추가 효과는 −2.91점
  • 근거퇴원 3개월 시점 두 군 차이 유의(P=.02) / 복약 순응도(변화 차이 1.76점, P<.001)·삶의 질도 함께 개선
  • 보완파일럿 판정을 p값 하나가 아닌 평균 변화량·이해도·시청 완료율·간호시간으로 함께 판단(기획안 3-1)

Q4인건비 절감 산정의 근거

선행 연구 두 편 모두 간호시간을 측정하지 않음. 「15분」은 무엇을 근거로 했고, 세브란스병원 1,345건을 쓴 연 464만~696만 원은 얼마나 믿을 수 있는가?

답변 예시

  • 인정15분은 현행 구두 설명 시간 기준 가정, 논문 근거 없음 / 696만 원은 최대치 시나리오
  • 근거분당 인건비 345원은 보건복지부 실태조사[3] 기준 / 1,345건은 우리 병동 공개 자료 부재로 쓴 참고 수치[4]
  • 보완도입 전 1~2주간 구두 설명 시간 실측, 도입 후 보충 설명 시간 포함 재측정, 우리 병동 연간 건수로 교체

Q5비용 대비 효과

3D 영상 제작비·전문의 감수·태블릿·수정 비용이 모두 「미확정」임. 투자비 회수까지 몇 년이 걸리는가?

답변 예시

  • 인정비용 미산정, 현재 회수 기간 확정 불가
  • 계산 틀투자 회수 기간(년) = 총 초기 제작·도입비 ÷ 연간 실제 절감액
  • 보완업체 견적 2~3곳 확보, 기존 병동 태블릿 활용 여부 확인, 무료 영상 재활용안과 비교
  • 추가불안 감소·복약 순응도 향상[1]은 금액으로 환산되지 않는 효과임

Q6대상자 일반화

[1]은 중국 단일 기관, 평균 61세, 인지기능 검사(Mini-Mental State Examination, MMSE) 기준 미달자 제외 연구임. 기기 조작이 미숙한 70대, 인지 저하 가능성이 있는 환자에게도 적용 가능한가?

답변 예시

  • 인정[1] 대상이 더 젊고 인지 저하자 제외, 우리 대상과 차이 있음
  • 근거큰 자막·느린 말속도·성우 나레이션, 버튼 1개 화면, 간호사 첫 재생 지원으로 고령자 접근성 보완
  • 보완이해도 3문항 오답 시 재시청 + 간호사 보충 설명 / 파일럿에서 연령대별 시청 완료율·이해도 별도 분석

Q7평가 설계의 실행 가능성

시술 직전 APAIS, 퇴원 3개월 후 SAS, 퇴원 후 지식 재측정까지 도구와 시점이 많음. 소규모 파일럿에서 실제로 모두 측정 가능한가, 몇 명으로 판단하는가?

답변 예시

  • 인정측정 부담 큼, 표본 수 미정
  • 근거APAIS는 6문항으로 짧은 시술 전 불안 전용 도구 / SAS는 [1]과 직접 비교용 / 지식 재측정은 [2]에서 단기(2일) 차이 없음 확인
  • 보완1차 판정은 시술 직전 APAIS로 한정, 3개월 SAS·지식은 2차 지표로 운영 / 표본 수는 통계 자문 후 확정
